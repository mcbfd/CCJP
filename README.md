# CCJP — Plateforme du Conseil Consultatif de la Jeunesse de Podor

Plateforme institutionnelle (site public + back-office) du **Conseil Consultatif de la
Jeunesse de Podor (CCJP)**, département de Podor, région de Saint-Louis, Sénégal.

**Objectifs :** informer · réunir la jeunesse podoroise · vulgariser les activités
de chaque commission.

## Stack

Next.js 15 (App Router) · Supabase (PostgreSQL, Auth, Storage) · Tailwind CSS v4 · Vercel

## Document de référence

➡️ **[`PLAN_IMPLEMENTATION.md`](./PLAN_IMPLEMENTATION.md)**

Plan d'implémentation complet : vision et objectifs, périmètre fonctionnel,
architecture, modèle de données PostgreSQL (schéma SQL + politiques RLS),
spécifications par module, design system, sécurité, découpage en sprints,
méthode d'exécution sur Google Antigravity, déploiement Vercel et recette.
